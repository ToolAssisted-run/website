The grouping proposal, for review

All 269 ungrouped games surveyed. Groups are families (one franchise across systems), never genres, so a game with no relatives stays ungrouped: 175 games remain standalone under this proposal, which is correct, not lazy. 16 games join existing groups and 29 new groups gather 78 more. Amber flags mark the judgment calls; strike anything you disagree with and I execute the rest, every move a logged act.
