Hero input reel

The icon's piano-roll motif, rolling forward behind the welcome box. Motion is frame-quantized (CSS steps(), one input column per tick, no easing), the pattern is the ink color at low opacity so both themes carry it, and reduced-motion users get a still reel. Tune it live; the second stage shows the same settings on dark.
