# toolAssisted.run — website

The website of [toolAssisted.run](https://toolassisted.run), an open community
archive of tool-assisted speedruns.

- `index.html` — the live landing page
- `generator/` — the static site generator: reads
  [the archive](https://github.com/ToolAssisted-run/archive) and emits the site
  (staging build at [toolassisted.run/stage](https://toolassisted.run/stage/))
- `DESIGN.md` — the canonical design record; read it first
- `deploy.sh` — FTP deploy for the landing page
