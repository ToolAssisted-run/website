Tools

You can create your run with any emulator and any tools you like; you only need to submit the encoded video. Below are the TAS tools commonly used.

Need help with any of these tools? Ask on our forum or on our Discord server; somebody who uses it will point you the right way.

in development

Chimera is this site's endorsed emulator: a derivative fork of BizHawk that keeps its TAS toolchain (movies, savestates, TAStudio, RAM tools, Lua) and removes everything else, most importantly every emulation core. Four ideas drive it:

  • Modularity: cores are external, self-contained packages, each in its own repository, loaded explicitly like a ROM.
  • Lightweight: one audio driver, one display driver, one adapter for every core, nothing else.
  • Performance: the machinery lives in a native engine that also runs headless and links into bots and solvers directly.
  • Reproducibility: a movie's contract is the pair (movie, core package); movies record the exact core version, package hash, firmware hashes and host provenance, and every change passes a witness gate that byte-compares emulator memory against goldens.

The frontend, the TAS tooling and the architecture are the original work of the BizHawk team; all credit for them belongs to BizHawk's developers. Follow it on GitHub.

Botting and brute-forcing tools

jaffarPlus

A high-performance botting engine for routing and solving games by massive state-space search. Source on GitHub.

AdvancedBot

A botting external tool for BizHawk, searching inputs from inside the emulator itself, by toca. Source on GitHub.
