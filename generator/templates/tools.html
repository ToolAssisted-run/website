Tools

You can create your run with any emulator and any tools you like; you only need to submit the encoded video, and the movie file if one exists. Below are the TAS tools commonly used.

Need help with any of these tools? Ask on our forum or on our Discord server; somebody who uses it will point you the right way.

miniHawk in development

miniHawk is this site's endorsed emulator, a re-implementation of BizHawk built around three ideas: modular emulation cores, performance, and a higher standard of reproducibility: every core runs waterboxed, and the movie format carries extended build environment metadata. Follow it on GitHub.

Botting and brute-forcing tools

jaffarPlus

A high-performance botting engine for routing and solving games by massive state-space search. Source on GitHub.

AdvancedBot

A botting external tool for BizHawk, searching inputs from inside the emulator itself, by toca. Source on GitHub.
