Tools

You can create your run with any emulator and any tools you like; you only need to submit the encoded video. Below are the TAS tools commonly used.

Need help with any of these tools? Ask on our forum or on our Discord server; somebody who uses it will point you the right way.

in development

Chimera is this site's endorsed TAS emulator, currently under development. Its main features are:

  • Any console, one tool: emulation cores are separate packages you load like a ROM; when a new core exists, Chimera already runs it.
  • Nothing in your way: no menus for systems you don't own, no databases, no clutter; the frontend does TAS work and gets out of the way.
  • Fast where it counts: the engine is native code and runs without the GUI too, so bots and solvers can hammer it at full speed.
  • New systems, first TAS ever: the core packages open the door to platforms that never had a TAS tool before; runs nobody could make until now.

Chimera is a derivative work of BizHawk, under the same MIT license and with full credit to its developers.

Botting and brute-forcing tools

jaffarPlus

A high-performance botting engine for routing and solving games by massive state-space search. Source on GitHub.

AdvancedBot

A botting external tool for BizHawk, searching inputs from inside the emulator itself, by toca. Source on GitHub.
