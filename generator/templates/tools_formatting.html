Notes

  • The notes are Markdown as GitHub writes it, with the additions listed above. Anything not listed renders as plain text; nothing breaks, it just is not special.
  • On the submission form, Ctrl/Cmd+V over selected text opens a link confirmation when the clipboard contains an HTTP(S) URL; ordinary paste is unchanged otherwise. Press Enter to confirm.
  • HTML is never rendered: tags show as the text you typed.
  • Where this comes from: headings, emphasis, lists, quotes, code, links, images, tables, strikethrough, bare-URL links and footnotes are standard Markdown (CommonMark and GitHub's additions), so they read the same on GitHub and most other sites. Definition lists, {% raw %}{#id .class}{% endraw %} attribute lists, [text]{.small} spans and :::name blocks are widely used extensions (from Pandoc, MyST and Docusaurus) that GitHub does not render. The names and options used here (quote, tabs, toc, embed, the span classes) and the [M100001] and [user:Name] references belong to this site. Outside this site, only the standard parts will render; the rest shows as text.
  • Rules for games and categories use the same formatting.
